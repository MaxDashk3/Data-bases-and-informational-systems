# Лабораторна робота №1
У даній лабораторній роботі було виконано наступні операції:
- Створення бази даних
- Додавання таблиць до бази даних з первинними і зовнішніми ключами
- Додавання даних до таблиць
- Вибірка даних з таблиць
- Оновлення даних у таблицях
- Видалення даних з таблиць

Запити містяться у файлі "requests.sql"
Скріншоти роботи містяться у звіті "Lab1.docx"
